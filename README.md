# TradingView Chart by BroLysis 

A clean, professional interface for viewing TradingView charts across multiple financial markets. Features a modern, responsive design with a 15-minute delayed data feed.

## Features 

- **Multi-Asset Charting**: View charts for various markets:
  - Equity Indices (Dow Jones 30, Nasdaq 100, S&P 500)
  - Forex (EUR/USD, GBP/USD, USD/JPY, and more)
  - Commodities (Gold, Silver, WTI Crude Oil)

- **Professional Chart Features**:
  - TradingView Advanced Charts
  - Technical indicators (ADX, MACD)
  - Customizable timeframes
  - Interactive chart tools
  - 15-minute delayed data

- **User Experience**:
  - Modern, responsive design
  - Dark theme for comfortable viewing
  - Animated transitions
  - Mobile-friendly interface

## Using the Charts 

1. **Select Your Market**:
   - Visit the landing page
   - Choose from various market categories
   - Click on your preferred market to view its chart

2. **Chart Features**:
   - Zoom in/out for different timeframes
   - Add technical indicators
   - Draw trendlines and other chart patterns
   - Change chart types (candlestick, line, etc.)

## Technical Details 

- **Frontend Technologies**:
  - HTML5
  - CSS3 (Tailwind CSS)
  - JavaScript
  - TradingView Charting Library

- **Features**:
  - Responsive design with Tailwind CSS
  - AOS (Animate On Scroll) for smooth animations
  - Clean and intuitive interface

## Getting Started 

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/TradingViewChart.git
   ```

2. Open `index.html` in your web browser to start viewing charts
